create a new repository on the command line:
--------------------------------------------
echo "# DataScienceWithMachineLearningCourse" >> README.md
git init
git add .
git commit -m "Add Jupyter notebook"
git branch -M main
git remote add origin https://github.com/javajohnsonloyola/DataScienceWithMachineLearningCourse.git
git remote -v
git push -u origin main

To add new files or update files on the same project directory:
--------------------------------------------------------------
git status
git add .
git commit -m "update"
git push

push an existing repository from the command line:
------------------------------------------------------
git remote add origin https://github.com/javajohnsonloyola/DataScienceWithMachineLearningCourse.git
git branch -M main
git push -u origin main
